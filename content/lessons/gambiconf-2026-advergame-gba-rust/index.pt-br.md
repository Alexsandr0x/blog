Palestra na GambiConf 2026 sobre como fazer um advergame para Game Boy Advance em 2026, escrito em Rust com a biblioteca `agb`.

A conversa passa pelo hardware do GBA (VBlank, VRAM, OAM, sprites), pelo fluxo de build que gera a ROM, pelo backend de ranking e pela tela de compartilhamento, que transforma cada partida em uma imagem pronta para Stories. Fecha com um QR Code para a plateia jogar na hora.

Os slides são uma página HTML. Navegue com as setas do teclado e rode as demos de ROM direto no navegador.
