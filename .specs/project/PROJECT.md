# Project: alexsandro.dev blog

## Vision
A personal technical blog in Portuguese (with English translations) for Alex — a data engineer writing about Python, data engineering, robotics, and software concepts. Hosted on GitHub Pages at alexsandro.dev.

## Goals
1. Share technical knowledge with the community (pt-br audience primarily)
2. Demonstrate expertise in data engineering, Python, and related areas
3. Maintain a clean, fast, minimal reading experience

## Audience
- Portuguese-speaking developers and data professionals (primary)
- English-speaking audience (secondary, via translations)

## Content Pillars
- **Posts**: In-depth technical articles (data engineering, Python, concurrency, web scraping, etc.)
- **Lessons**: Educational content for beginners (currently empty — planned)
- **About**: Author bio and professional background

## Tech Constraints
- Static site only (GitHub Pages — no server-side rendering)
- Hugo + Risotto theme (git submodule)
- CI/CD via GitHub Actions
- No budget for paid hosting/services
